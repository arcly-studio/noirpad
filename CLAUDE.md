# CLAUDE.md – NoirPad

Local notes app: FastAPI backend (`noirpad/`), vanilla-JS frontend (`static/`), desktop shell
`desktop.py` (WebView2), web variant `NoirPad-web.py`.

## Commands
- Python tests: `.venv\Scripts\python.exe -m pytest` (deps: `requirements-dev.txt`).
- JS tests: `npx vitest run` (`npm test`; tests in `tests/js`).
- Build: `build.ps1` (refuses to run unless `git status` is clean; see `BUILD.md`).
- **No bundler**: `static/` is served as-is. Edit and reload.
- Vendor files (fonts, markdown-it, DOMPurify, highlight.js, icons) are generated from
  `node_modules` with `npm run vendor` (`tools/vendor.mjs`). Never hand-edit `static/vendor/`.

## UI structure (`static/index.html`)
- Top bar `#top-bar`: `#top-bar-title`, `#tab-bar` (tabs, `static/js/tabs.js`), `#top-tools`
  (icon buttons). `static/js/topbar.js` holds `NP.icon`, `NP.menu` (shared popup menu), the
  Export and ⋯ menus (incl. `md_split` toggle).
- Sidebar: `#sidebar-search` opens find-all (`find-all.js`, Ctrl+Shift+K); NOTES / TAGS sections;
  `tree.js` = tag filter (`NP.tree.tagFilter`), ARIA tree with keyboard, context menu with
  rename / "Move to…" (`_openMoveMenu`) / delete.
- Note header `#note-header`: `#note-title-row` (rename in place -> `NP.app.renameNote`) and
  `#tag-bar` (rendered by `tags.js`).
- "by Arcly Studio" link: About in Settings (`#about-by`, filled by `settings.js`, key
  `ui.settings.by`) and the start page (`welcome.js`, `.welcome-by`, key `welcome.by`). Data comes
  from `NP.appInfo` (`app.js`, from `/api/version`).
- Editor / preview have no frames. Status bar: `#status-label` (● saved / ○ not saved, driven by
  `NP.editor._setSaveStatus` / `_renderStatus` in `editor.js`), `#mode-label`, counts.

## Icons
- Lucide (`lucide-static`, ISC; Feather-derived icons MIT – both in
  `static/vendor/lucide/LICENSE`). Sprite `static/vendor/lucide/sprite.svg` is generated by
  `tools/vendor.mjs` from its `ICONS` list.
- Add an icon: add the name to `ICONS`, run `npm run vendor`, then use `NP.icon("name")` or
  `<svg class="np-icon"><use href="/static/vendor/lucide/sprite.svg#i-name"></use></svg>`.
- `tests/test_icons.py` fails if a used icon is missing from the sprite.

## Logo (M1 "Glass sheets")
- Sources: `docs/brand/noirpad-icon.svg` (use at >= 40 px) and `noirpad-icon-small.svg`
  (<= 32 px). Copies in `static/img/` must be identical (`tests/test_brand.py` checks it).
- In the UI only as `<img class="... np-decorative">`, never inline (the SVG has `id`s).
- Icon URLs carry `?v=__NP_VERSION__`; `noirpad/app.py` (`VERSION_MARK`) fills it in
  `index.html` and `manifest.json` (cache busting).
- The logo is green (main tone `#00ff41`). Every raster (PNGs, `noirpad.ico`, `favicon.ico`, wizard
  BMPs, `social-preview.png`) comes from the two SVGs via `tools/make_icons.py`; never edit a
  raster by hand. After touching an SVG run it and commit the outputs and `docs/brand/icons.json`
  (`tests/test_brand.py` checks hashes and that every icon is green).
- Windows may show the old icon from its icon cache for a while; not a bug.

## Noir effects (glow, falling-code rain, CRT)
- Data keys `glow_enabled`, `matrix_rain_enabled`, `crt_enabled`; all `False` in
  `noirpad/storage.py` `DEFAULT_DATA` (also in `models.py`).
- One-time migration for pre-redesign data: `_migrate_noir_effects` -> `_noir_effects_upgrade`
  (keeps old look: glow on, rain unless explicitly off). `glow_enabled` present = already done.
  Also applied to a snapshot restored after a damaged data file.
- Frontend: `settings.js` `effects()`, `applyEffects()`, `setEffects({glow,matrix,crt})`;
  `effects.js` and `matrix-rain.js` call `setEffects`. Rain command `:rain` (`:matrix` = hidden
  alias). While it runs, `body.np-rain-on` makes `#editor-wrapper` see-through at `--rain-veil`
  (per theme, `test_contrast.py`); top bar and note header stay opaque. CRT used to live in localStorage
  (`migrateCrt` moves it).
- CSS: `body:not(.np-glow) * { text-shadow: none !important }` (top of `noirpad.css`); glow
  variables are set to 0 while effects are off. Do not add text-shadow outside this rule's reach.

## Design tokens / theming
- Theme ids (`matrix`, `dracula`, …) are internal: saved `theme`, `data-theme`. Users see the
  names in `themes.<id>` (locales) and type the `:theme` names from `NP.THEME_SLUGS` (`utils.js`);
  an old id still works as a hidden alias. No other product's name in the UI, help, commands or
  README. The original palette names (capitalised) may appear only in `THIRD-PARTY-NOTICES.txt`;
  `tests/test_theme_names.py` scans every file in the repo.
- `static/css/themes.css` (17 themes). Tokens added in the redesign: `--font-brand`, `--bg-panel`,
  `--folder-color`, `--code-bg`, `--accent-soft`, `--danger`; later `--control-off`,
  `--control-off-track` (grey off state of toggles) and `--md-src-text` (plain text in the
  Markdown source). Use tokens, not hard-coded colours.
- Markdown source colouring: `static/js/md-source.js` renders the underlay `#md-highlight` beneath
  the textarea `#editor-md` (drawn transparent while in sync); keep font metrics and scrolling identical.
- `tests/test_contrast.py` checks all 17 themes: text incl. `--fg-muted` and `--danger` >= 4.5:1 (muted is text), icons / toggle outline >= 3:1. Run it after
  touching any theme colour.
- The shared window style (dialogs, menus, popups) is the block "G7" at the end of `noirpad.css`.
  Reuse it for new windows.

## Tabs, saving, closing (frontend flow)
- `NP.tabs.add/activate/close` are async (Promise): `true` done, `false` user chose to stay,
  `null` superseded by a newer call. Always `await` them; never assume the tab switched.
- `NP.editor.leave()` saves the note before a switch/close and asks (discard / stay) if saving
  fails. `NP.editor.save()` returns true/false and runs one at a time (`_saving` queue: overlapping
  saves would send the same old `rev`). Rename and tag writes must target the note id they were
  started for, not the "current" one.
- Desktop close: `flushForClose` -> "close"/"stay"; `NP.editor._closeBusy` makes `desktop.py` wait
  (`CLOSE_BUSY_LIMIT`) while a save or question is pending.
- Integration harness `tests/js/flow.js`: real state/tabs/editor/tree over a fake server. Rule:
  every fix that goes through tabs gets an integration test (`flow-*.test.js`) that fails without
  the fix.

## Store edition (MSIX, N1.9)
- `noirpad/edition.py`: `github` | `store` (package identity; `NOIRPAD_EDITION` overrides).
  Store data folder `%USERPROFILE%\NoirPad` (MSIX virtualizes AppData). `/api/version` has `edition`.
- `noirpad/store_import.py`: one-time COPY of the GitHub edition's `notes_data.json` + `images/`
  (copy2, never written into the source; not while the GitHub edition runs: installer mutex or
  data lock). `backups/` / `corrupt-*` are never copied (user's decision A). Toast notices
  `github_imported` / `github_import_blocked` (no dialog). With `NOIRPAD_DATA_DIR` set the source
  is only `NOIRPAD_IMPORT_FROM` (tests never read real data).
- Store data with own notes is never overwritten: the start shows `github_import_skipped` once
  (`github-import-skipped.json`) and Settings → Data offers "Add notes from the installer version"
  (`noirpad/store_merge.py`, `/api/store/installer-notes`): adds into a new folder, new ids / image
  names on collision, all or nothing (pre-import zip, images, one atomic data write, then the marker).
  In the UI the GitHub edition is "the installer version"; no "GitHub" in locales (test).
- Never write next to the exe: the MSIX install folder is read-only. `build-msix.ps1` smoke-tests
  the layout writable (no file may change) and write-protected with icacls.
- `tools/msix_manifest.py` writes AppxManifest.xml (version X.Y.Z.0, MinVersion 10.0.17763.0 with
  the reason in its docstring). MSIX images: `tools/make_icons.py` -> `store/Assets/`.
- `tools/test-cert.ps1 -Create` / `-Remove` (N1.11, never run without the user's yes): self-signed
  cert with Subject = manifest Publisher, private key non-exportable in `CurrentUser\My`, signed TEST
  packages X.Y.Z.0 and X.Y.Z.1 (upgrade test; that version never in git) in `dist\msix-test\`,
  both smoke-tested, only the public `.cer` exported. Partner Center gets only the unsigned
  `dist\msix\NoirPad-<version>.msix`. Trusting the `.cer` in
  `LocalMachine\TrustedPeople` is the user's manual admin step.
- Test certificate, installing the MSIX and WACK only in N1.11 after the user's explicit yes.

## Backend notes
- Notes carry `rev`; saves send `base_rev`; mismatch -> 409 `note_changed_elsewhere` (two web windows).
- Poll ETag: `storage.update_data_tracked` returns before/after; header `X-NoirPad-ETag-Before`
  lets the client skip re-downloading after its own save.
- Route handlers without `await` are plain `def` (thread pool). Only upload/import are `async`;
  `test_r8_*` enforces it. Heavy work in async handlers: `run_in_threadpool`. Shared state checked
  and then changed needs a lock: password tries go through `server_auth.guarded_attempt`.
- Log is anonymized: `logs.PrivateFormatter` writes the profile path as `~`. Never log the user name.

## Dialogs / shortcuts
- Custom windows use `NP.modal` (`dialog.js`: role=dialog, focus trap, focus return). Help is in
  the G7 style; its shortcuts come from `NP.shortcuts` (current mapping), not hard-coded text.
- NoirPad-web (browser) uses Alt+Shift+N/T/I instead of Ctrl+Shift+N/T/I (browser owns them):
  `WEB_DEFAULTS` in `shortcuts.js`; desktop keeps the Ctrl defaults.

## Dokumentace knihoven (Context7)
- Kód, který volá API knihovny třetí strany (nový i upravený), ověř přes Context7 MCP:
  `resolve-library-id` -> `query-docs`. Nespoléhej na paměť.
- Hlavně: FastAPI, Starlette, uvicorn, pydantic, cryptography, platformdirs, pywebview,
  pythonnet, PyInstaller, Inno Setup, markdown-it, DOMPurify, highlight.js, Lucide, vitest,
  jsdom, pytest.
- Verze jsou připnuté (`requirements*.txt`, `package.json`, `static/vendor/VERSIONS.json`).
  Hledej dokumentaci k té verzi (ID `/org/project/verze`, když ji Context7 nabízí). Novější API
  nepoužívej, dokud se verze nezvedne.
- Pravidla tohoto souboru mají přednost: žádné CDN, žádný bundler, `static/vendor/` jen přes
  `npm run vendor`.
- Na vlastní kód NoirPadu Context7 nepoužívej, čti ho přímo v repu.

## Conventions
- i18n: every visible text via `NP.t(...)` or `data-i18n*` attributes; keys in
  `static/locales/en.json` and `cs.json` (identical key sets, both updated together).
- Build DOM with `textContent` / DOM APIs. Never `innerHTML` with user data.
- Commit messages in Czech, with a `Co-Authored-By` line.
- Tests/manual checks only in your own instance with a temporary `NOIRPAD_DATA_DIR`. Never touch
  the user's running NoirPad, their data, the clipboard or their other apps.
- Windows: use absolute paths; PowerShell is the primary shell.
